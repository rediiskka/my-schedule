# Карта для агента

Где что лежит и в каком порядке это читать. Файл публичный, поэтому здесь только
адреса и порядок — ни паролей, ни адреса сервера памяти.

## Порядок при старте

1. **Оглавление проектов** — заметка `toc` в проекте памяти `main`. Оттуда видно,
   какие проекты есть и какой активен.
2. **Контекст этого проекта** — `my-schedule/docs/status-i-progress`: статус,
   принятые решения, грабли.
3. **План работы** — `docs/plan.kdl`, **лежит в репозитории**:
   читается вместе с кодом, без внешней памяти. Смотреть:
   `node ~/.claude/skills/plan-and-iterate/plan.mjs where 6`.
   Копия в памяти (`my-schedule/План`) — для того, у кого нет доступа к репозиторию;
   при расхождении сверяться по `updated=`.
4. **Правила кода** — `CLAUDE.md` в корне, обязательны к соблюдению.
5. **Устройство шифрования** — `docs/how-it-works.md`: формат файлов, вывод ключа,
   что видно постороннему.

## Что во внешней памяти

Сервер памяти — тот, что подключён у владельца репозитория; здесь он не называется.
Все обращения — с явным `project=`, значение по умолчанию неверное.

| Заметка | Что внутри |
| --- | --- |
| `main/toc` | оглавление всех проектов, отметка активного |
| `my-schedule/docs/status-i-progress` | статус, решения, грабли |
| `my-schedule/docs/pravila-razrabotki` | архитектура и правила кода |
| `my-schedule/docs/sekrety` | пароль от расписания |
| `my-schedule/План` | копия `plan.kdl` |

## Что на диске и не в git


| Путь | Что это |
| --- | --- |
| `.env` | `SCHEDULE_PASSWORD` — пароль для `tools/vault.py`, единственное, что не в git |

## Синхронизация

**Файл первичен, память — копия.** Порядок всегда один: правим файл, затем
копируем в память. Обратное направление — только когда файла нет.

Сверка по метке `updated=` на корневом узле плана: свежая выигрывает, при равных
прав файл. Метку ставит `plan.mjs touch`, а не рука.

## Работа с расписанием

Записи правит только `tools/vault.py` с машины — сайт статический и писать в
репозиторий не может. Пароль он берёт из `--password`, `SCHEDULE_PASSWORD` или
`.env`. Из веба, где `.env` недоступен, пароль берётся из заметки `docs/sekrety`
и передаётся аргументом.

```bash
python tools/vault.py list
python tools/vault.py add --subject "..." --date ДД.ММ.ГГГГ --pair 3
```

После правки — обычный коммит и push; Pages подхватит файлы за минуту-две.
