# Моё расписание

Личный сайт на базе [raspisanie-3bi1](https://github.com/rediiskka/raspisanie-3bi1):
те же пары 3БИ1, плюс мои задачи и цели поверх них. Один `index.html`, без
сборщиков и внешних библиотек — статика, открывается прямо в браузере.

Запуск: `python -m http.server 8742` из корня, открыть `http://localhost:8742`.

## Как это устроено

- **Пары** — из `data.json`, тот же файл, что и в исходном репозитории (публичное
  расписание группы, обновляется тем же `tools/build_from_pdf.py` из соседнего
  проекта — просто скопировать свежий `data.json` сюда при пересборке семестра).
  Чужая подгруппа зашита как отфильтрованная в `match()` (`MY_SUBGROUP` в
  скрипте) — показываются только общие пары и моя 2-я подгруппа.
- **Задачи и цели** — в `tasks.json` и `goals.json` рядом в репозитории,
  зашифрованные паролем. Каждый пункт лежит своим фрагментом: новый дописывается
  одной строкой, прежние не переписываются. Задачи совмещаются с парами в
  списке, неделе, месяце и попапе дня.
- **Сайт их только читает.** Pages отдаёт статику, писать в репозиторий из
  браузера нельзя, поэтому формы задачи в интерфейсе нет: заведённая в браузере
  задача осталась бы в этом браузере. Файлы правит `tools/vault.py` с машины,
  результат уезжает коммитом и на всех устройствах появляется сразу.
- **Пароль** — и вход, и ключ к файлам. В `index.html` лежит только SHA-256-хэш
  (`PASSWORD_HASH`), коммитить его безопасно; сам пароль в репозиторий не
  попадает — он в `.env`, который в `.gitignore`.

Подробности формата, вывода ключа и того, что видно постороннему, —
в [docs/how-it-works.md](docs/how-it-works.md).

## Работа с задачами

```bash
python tools/vault.py list tasks.json
python tools/vault.py add tasks.json --title "Сдать курсовую" --date 2026-09-10 --time 14:00
python tools/vault.py edit tasks.json --id 5019e955 --time 16:00
python tools/vault.py rm  tasks.json --id 5019e955
```

Цели — то же самое с `goals.json` и полями `--horizon` (`month`/`season`) и
`--period`.

## Известные ограничения

- Неделя/месяц навигация ограничена датами семестра из `data.json`
  (01.09–29.12.2026) — так же, как в исходном сайте. Задача с датой внутри
  этого диапазона видна везде; вне диапазона видна в месяце (в «пустых»
  клетках), но не в списке — список идёт по дням `data.json`.
- Отметка «сделано» ставится утилитой, а не на сайте: сайт ничего не пишет.
- Потеря пароля — потеря задач. Расшифровать файл без него нельзя по построению.
- «Скачать PNG» рисует только пары, задачи в картинку не попадают.
