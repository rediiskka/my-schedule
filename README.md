# Моё расписание

Личный сайт на базе [raspisanie-3bi1](https://github.com/rediiskka/raspisanie-3bi1):
те же пары 3БИ1, плюс мои личные задачи поверх них. Один `index.html`, без
сборщиков и внешних библиотек — статика, открывается прямо в браузере.

Запуск: `python -m http.server 8731` из корня, открыть `http://localhost:8731`.

## Как это устроено

- **Пары** — из `data.json`, тот же файл, что и в исходном репозитории (публичное
  расписание группы, обновляется тем же `tools/build_from_pdf.py` из соседнего
  проекта — просто скопировать свежий `data.json` сюда при пересборке семестра).
  Чужая подгруппа зашита как отфильтрованная в `match()` (`MY_SUBGROUP` в
  скрипте) — показываются только общие пары и моя 2-я подгруппа.
- **Личные задачи** — свой слой поверх пар: хранятся только в `localStorage`
  этого браузера и никогда не коммитятся в git. Кнопка «Добавить задачу» в
  меню, задачи совмещаются с парами в списке, неделе, месяце и попапе дня.
  Лежат зашифрованными (см. ниже), а рядом есть «Экспорт» и «Импорт» —
  обычный JSON-файл, которым задачи переносятся в другой браузер и который
  служит резервной копией.
- **Пароль** — и вход, и ключ к задачам. В `index.html` лежит только
  SHA-256-хэш (`PASSWORD_HASH`), коммитить его безопасно, сам пароль в
  репозиторий не попадает; как сменить — комментарий у константы.
- **Шифрование задач** — из пароля выводится ключ (PBKDF2, 150000 итераций),
  им шифруется localStorage (AES-GCM). Соль лежит открыто, ключ живёт в
  `sessionStorage` до закрытия вкладки. Без пароля задачи не прочитать —
  поэтому «Экспорт» и нужен: забытый пароль иначе означал бы их потерю.

## Известные ограничения

- Неделя/месяц навигация ограничена датами семестра из `data.json`
  (01.09–29.12.2026) — так же, как в исходном сайте. Задача с датой внутри
  этого диапазона видна везде; вне диапазона видна в месяце (в «пустых»
  клетках), но не в списке — список идёт по дням `data.json`.
- Личные задачи не синхронизируются между устройствами автоматически — это
  чистая статика без сервера. Перенос — через «Экспорт» и «Импорт» файлом.
- «Скачать PNG» рисует только пары, личные задачи в картинку не попадают.
