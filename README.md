# Моё расписание

Личный сайт на базе [raspisanie-3bi1](https://github.com/rediiskka/raspisanie-3bi1):
те же пары 3БИ1, плюс мои записи поверх них. Один `index.html`, без
сборщиков и внешних библиотек — статика, открывается прямо в браузере.

Запуск: `python -m http.server 8742` из корня, открыть `http://localhost:8742`.

## Как это устроено

- **Пары** — тянутся напрямую из [raspisanie-3bi1](https://github.com/rediiskka/raspisanie-3bi1):
  расписание обновляют там, здесь оно появляется само. Копии в этом репозитории
  нет намеренно — её пришлось бы помнить обновлять. Чужая подгруппа зашита как
  отфильтрованная в `match()` (`MY_SUBGROUP` в скрипте): показываются только общие
  пары и моя 2-я подгруппа.
- **Свои записи** — в `my-data.json` и `index.json` рядом в репозитории,
  зашифрованные паролем. Запись устроена как занятие: предмет, тип,
  преподаватель, аудитория, — и встаёт в ту же сетку, отличаясь розовой меткой.
  Каждая лежит своим фрагментом: новая дописывается одной строкой, прежние не
  переписываются. Индекс читается первым, поэтому расшифровывается только
  показанный отрезок, а не весь файл.
- **Сайт их только читает.** Pages отдаёт статику, писать в репозиторий из
  браузера нельзя, поэтому формы записи в интерфейсе нет: заведённая в браузере
  запись осталась бы в этом браузере. Файлы правит `tools/vault.py` с машины,
  результат уезжает коммитом и на всех устройствах появляется сразу.
- **Наложения видно.** Если запись попадает на занятие, они рисуются одним
  блоком с пунктиром — своё сверху. Пары можно вовсе убрать рубильником «Пары».
- **Пароль** — и вход, и ключ к файлам. В `index.html` лежит только SHA-256-хэш
  (`PASSWORD_HASH`), коммитить его безопасно; сам пароль в репозиторий не
  попадает — он в `.env`, который в `.gitignore`.

Подробности формата, вывода ключа и того, что видно постороннему, —
в [docs/how-it-works.md](docs/how-it-works.md).

## Работа с задачами

```bash
python tools/vault.py list
python tools/vault.py list --from 07.09.2026 --to 13.09.2026
python tools/vault.py add --subject "Курсовая: глава 2" --date 10.09.2026 --pair 3
python tools/vault.py add --subject "Тренировка" --date 04.09.2026 --time 19:00 --duration 60
python tools/vault.py edit --id 5019e955 --time 16:00
python tools/vault.py rm  --id 5019e955
```

Ключ `--local` пишет в `my-data.local.json` — этот слой виден только при запуске
с localhost и в репозиторий не уезжает: там живут выдуманные записи для проверки
вёрстки.

## Известные ограничения

- Неделя/месяц навигация ограничена датами семестра из расписания группы
  (01.09–29.12.2026) — так же, как в исходном сайте. Задача с датой внутри
  этого диапазона видна везде; вне диапазона видна в месяце (в «пустых»
  клетках), но не в списке — список идёт по дням расписания.
- Записи правятся только утилитой: сайт ничего не пишет.
- Потеря пароля — потеря записей. Расшифровать файл без него нельзя по построению.
- «Скачать PNG» рисует только пары, свои записи в картинку не попадают.
