# Как работать с потоком дел

Дела приходят как приходят: «надо бы английский подтянуть», «в пятницу зал»,
«курсовая горит», «маме позвонить». Без дат, без порядка, вперемешку с мыслями.
Задача ассистента — разложить это в расписание, не потеряв и не переспросив
двадцать раз.

Модель дел — в [model.md](model.md). Здесь — как ей пользоваться.

## Правило первое: не выдумывать точность

Сказано «на неделе» — значит горизонт `week`, а не среда, 15:00. Придуманная
точность выглядит как решение владельца, и через день уже не отличить, кто её
выбрал. Точность повышается только двумя способами: владелец сказал, или
ассистент предложил и **пометил `placed=auto`**.

## Разбор потока

1. **Записать как есть.** Дело заводится сразу, с тем горизонтом, который слышен
   из формулировки. «Английский» без срока — `season`. Ничего не уточнять на
   этом шаге: поток важнее полноты, иначе половина забудется, пока выясняем.
2. **Спросить одним списком.** Когда поток кончился — уточнить непонятное разом,
   а не по одному вопросу на дело.
3. **Разложить.** Дела с широким горизонтом разворачиваются в конкретные:
   `month` → несколько `day` или `time`. Порождённые получают `parent` — id
   исходного, и `placed=auto`.
4. **Показать и отдать решение.** Что расставлено автоматически, называется
   вслух: «поставил зал на вторник и четверг 19:30, потому что там пусто после
   пар». Владелец подтверждает или двигает.

## Куда ставить время

Когда время выбирает ассистент:

- в окна между парами и после них, не внутрь занятия;
- не в день самостоятельной работы, если дело учебное — там и так завал;
- повторяющееся — в одни и те же часы, чтобы вошло в привычку;
- утренние дела не раньше первой пары, вечерние не позже 21:00.

Наложение допустимо только если владелец сам так поставил. Автоматически —
никогда: сайт для того и показывает конфликты, чтобы их не плодить.

## Недели не должны быть одинаковыми

Однообразие гасит интерес быстрее, чем нагрузка: если каждая неделя выглядит
одинаково, расписание перестают открывать. Поэтому повторяющееся раскладывается
с чередованием.

Чётность берётся из расписания группы — она там уже размечена, считать её
самостоятельно не нужно:

```bash
python tools/vault.py add --subject "Бассейн" --date 07.09.2026 --time 18:00     --repeat пн --until 29.12.2026 --parity odd
python tools/vault.py add --subject "Йога" --date 14.09.2026 --time 18:00     --repeat пн --until 29.12.2026 --parity even
```

Один и тот же час, разные занятия: в нечётную неделю бассейн, в чётную йога.

Как этим пользоваться при раскладке:

- одинаковое каждую неделю — только там, где важна привычка (язык, зарядка);
- всё остальное разводить по чётности: два похожих дела в один слот, но в разные
  недели;
- тяжёлое не ставить в одни и те же дни подряд — пусть чередуется с лёгким.

## Пересборка

Раз время `auto` — предложение, его можно снести и разложить заново:

```bash
python tools/vault.py replan --from 07.09.2026 --to 13.09.2026
```

Убираются только `placed=auto`. Всё, что владелец поставил сам, остаётся на
месте — это и есть смысл разделения.

Поводы пересобрать: изменилось расписание пар, появилось срочное дело, неделя
пошла не по плану.

## Чего не делать

- **Не молчать про автоматическое.** Расставил — сказал. Молча поставленное
  время выглядит как согласованное.
- **Не чинить формулировку.** «Пучить англ» остаётся как есть: это язык
  владельца, а не ошибка ввода.
- **Не выкидывать дела без срока.** `season` — нормальное состояние. Дело,
  которое некуда поставить, не удаляется, а ждёт.
- **Не решать за владельца, что важнее.** Приоритет — его; ассистент показывает
  конфликт и предлагает варианты.
